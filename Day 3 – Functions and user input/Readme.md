### What is a Python module ?
- A Python module is a single file containing Python code
- (with a .py extension) that defines functions, classes, and variables.
 
### WHat is random module in Python ?
- The random module is a built-in library in Python
- used to generate pseudo-random numbers and make random selections

### What is a while loop ?
- A while loop is a fundamental programming control structure that repeatedly
- executes a specific block of code as long as a designated condition evaluates to true
