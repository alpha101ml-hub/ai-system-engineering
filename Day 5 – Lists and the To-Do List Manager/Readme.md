### What is a Python dictionary ?
- A Python dictionary is a built-in data structure used to store data in key-value pairs,
- where each unique key maps directly to a specific value

### What is sys.exit() in Python ?
- The sys.exit() function in Python is the standard
- and recommended way to terminate a running program or script early

### What is a Python file (open(), read(), write()) ?
- In Python, file handling allows you to interact with external files
- stored on your computer using built-in functions like open(), read(), and write()
