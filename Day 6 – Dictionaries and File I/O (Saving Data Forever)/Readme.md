### What is sys.argv in Python ?
- In Python, sys.argv is a built-in list that stores the command-line arguments 
- passed to a script when it is executed

### What is if __name__ = '__main__' ?
- The construct if __name__ == '__main__': is a Python idiom used to check whether a script 
- is being executed directly by the user or being imported as a module into another script
