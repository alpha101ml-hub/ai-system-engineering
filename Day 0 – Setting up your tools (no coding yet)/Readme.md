### Goal: By the end of today, you will have a working Python installation and a GitHub account. You will not write any code yet – just prepare your environment.

Step 1: Install Python

What is Python?
Python is a programming language – a way to give instructions to your computer. We will use it to build AI models.

Your task:

    Open a web browser (Chrome, Firefox, Edge).

    Search for: “download Python”

    Click the first result (python.org/downloads).

    Click the big yellow button that says “Download Python 3.12.x” (or 3.11.x – any version 3.10 or higher is fine).

    Important: When installing, check the box that says “Add Python to PATH” (Windows) or on Mac just follow the default installer.

How to know it worked:

    On Windows: Open Start menu, type “Command Prompt”, open it. Type python --version and press Enter. You should see something like Python 3.12.2.

    On Mac: Open “Terminal” (search in Spotlight). Type python3 --version.

    If you see a version number → success. If not, Google: “python not recognized in terminal”.

Screenshot for GitHub: Take a picture/screenshot of your terminal showing the version. Save as python_version.png.
Step 2: Install a code editor – VS Code

What is a code editor?
A place where you write your programs. Like Microsoft Word, but for code.

Your task:

    Search: “download VS Code”

    Go to code.visualstudio.com/download

    Download the version for your operating system (Windows/Mac/Linux).

    Install it (accept all defaults).

    Open VS Code. You’ll see a window with icons on the left.

Optional but helpful:
Inside VS Code, go to Extensions (the square icon on the left) and search for “Python”. Install the one by Microsoft (it has 99M+ downloads). This gives you auto‑complete and error checking.

Screenshot: Your VS Code window open. Save as vscode.png.
Step 3: Create a folder for your learning

What is a folder?
Same as a directory – a place to store files. Your GitHub repo will be a folder on your computer.

Your task:

    On your Desktop (or anywhere you like), create a new folder called ai-efficiency-journey.

    Open VS Code. Click File → Open Folder (not Open File). Select the folder you just created.

    You will see the folder name in the left panel.

Why this matters: All your code will live here.
Step 4: Create a GitHub account

What is GitHub?
A website where you store your code online. Employers look at your GitHub to see what you’ve built.

Your task:

    Go to github.com

    Click “Sign up”. Enter your email, a password, and a username (choose something professional – e.g., yourname-ai).

    Verify your email.

    Once logged in, click the green “New” button or the plus sign (+) at the top right → “New repository”.

    Repository name: ai-efficiency-journey

    Keep it Public (so employers can see). Do NOT add a README yet (we will do that later).

    Click “Create repository”.

Now link your computer to GitHub:
Search: “git install” – download and install Git for your OS.
Then in VS Code, open a terminal: Terminal → New Terminal.
Type:
bash

git config --global user.name "Your Name"
git config --global user.email "your-email@example.com"

(Use the same email as your GitHub account.)

Then follow GitHub’s instructions to push your folder (we will do that properly tomorrow – for now just create the account).

Screenshot: Your GitHub repo page showing ai-efficiency-journey as an empty repository. Save as github_repo.png.
Step 5: Write your first “journal” entry

Inside VS Code, create a new file called journal.md in your folder.
Type today’s date and write 2‑3 sentences:

    “Day 0: I installed Python, VS Code, and created a GitHub account. I don’t know how to code yet, but my tools are ready. Tomorrow I will write my first Python program.”

Save the file (Ctrl+S).
